# DocShield AI 🛡️

DocShield AI is an intelligent document security and threat analysis platform designed to inspect, sanitize, and safeguard confidential documents and digital assets.

---

## 📂 Project Structure

```text
DocShield/
├── frontend/             # React + Vite + Tailwind CSS + Three.js Frontend Application
│   ├── public/           # Static assets
│   ├── src/              # React application source code
│   │   ├── components/   # UI components, security widgets, 3D Hero scanners
│   │   ├── pages/        # Application routes & dashboard pages
│   │   └── ...
│   ├── index.html        # HTML entry point
│   ├── package.json      # Dependencies and scripts
│   └── vite.config.js    # Vite configuration
└── README.md             # Project documentation
```

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Running Frontend
```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Built With

- **React 19** + **TypeScript**
- **Vite** - High performance build tool
- **Tailwind CSS v4** - Styling & responsive UI
- **Three.js** / **@react-three/fiber** - 3D visualizers and interactive scan simulations
- **Framer Motion** & **GSAP** - Smooth security dashboard animations
